# Certainty

How sure FieldMind is about one answer, in three levels used the same way everywhere.

| Level | Class | When |
|---|---|---|
| Confirmed | `fm-sure--yes` (solid ink) | The rep verified it in person |
| Likely | `fm-sure` (ink outline) | Sources point to it, but it isn't confirmed or may be out of date |
| Unknown | `fm-sure--no` (dashed) | Nothing found |

Put it beside an answer's label, not on every line of a screen. Never use a percentage.
