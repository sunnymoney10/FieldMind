# Tag

A short label for what changes the visit at this stop; one tag per stop in lists.

| Variant | Class | Use |
|---|---|---|
| Question | `fm-tag--question` (citron) | This stop's open question: "Verify occupant", "Decision-maker unknown" |
| Conflict | `fm-tag--conflict` (iron-oxide, white text) | "Don't contact", "Sources disagree", overdue |
| Info | `fm-tag--info` (aluminum) | "Return Nov 15", "MIMO" |
| Done | `fm-tag--done` (carbon) | "Enrolled" |

Never pink. Two or three words, sentence case. If nothing changes the visit, show no tag.
